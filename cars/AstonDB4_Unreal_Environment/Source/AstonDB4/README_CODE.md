Native implementation classes:
- DB4Environment: regenerated procedural terrain/road/markings, HISM forest/boulders/guardrails
- DB4VehiclePawn: first-person/third-person/orbit, steerable wheels, animated steering rim, input and simplified handling
- DB4GameMode: auto-spawns world lighting and environment in play mode
- DB4HUD: speedometer and control overlay

Unreal Python in Content/Python builds texture-backed PBR materials and imports the supplied GLB.
Source does not currently use Chaos Vehicles; no claim of physically validated tire dynamics.
